Third-party notices — Foundation through public-beta hardening

This development notice accompanies the Milestone 0–6 alpha dependency graph. Release automation must generate a complete SBOM and retain upstream licence texts before public distribution.

Top-level runtime selections:

Development-only Windows IPC regression fixtures retain two unmodified JavaScript
transport scripts from tauri 2.11.5, commit 7cd71369c00978a3783b6ae3e9972358abbe4ae6.
Their original copyright/SPDX headers, exact source paths and hashes, and full
chosen MIT license are in apps/desktop/test-fixtures/tauri-ipc/. These fixtures
run only in isolated tests with simulated responses, not the app bundle.

The local editor OCR path selects tesseract.js 7.0.0 and tesseract.js-core 7.0.0
(Apache-2.0), with locally served tessdata_fast 4.1.0 English/French models
(Apache-2.0). Native compiled libraries retain their individual permissive
licences; full texts and source commit inventory are in LOCAL_OCR_NOTICES.txt,
LOCAL_OCR_JS_NOTICES.txt and ocr-engine-review.json. Asset preparation ships
these texts as public/ocr/NOTICES.txt alongside the unchanged worker notice.
No Poppler/qpdf/native OCR container is included in the browser/Windows path.
This technical adoption review is not a legal certification or a complete
vulnerability clearance of the compiled native graph. Public release remains gated.

SBOM/notices and licence compatibility review remain required.

Next.js 16.3.8 optionally installs platform-specific `@img/sharp-*` 0.35.5 packages for server-side image optimization. These packages declare `Apache-2.0 AND LGPL-3.0-or-later` because they include libvips. The narrowly version-bound licence-check exception permits this dependency only in the web graph. PDFrig currently uses no Next.js image optimization, and the desktop application is a separate Vite/Tauri build whose bundled frontend cannot include this Node package. Preserve the applicable Sharp/libvips notices in any server distribution; adding it to a Windows installer requires a separate legal review and compliance plan. The September security patch review is enforced by the exact-version license policy.
